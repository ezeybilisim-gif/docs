Media Kütüphanesi, platforma yüklenmiş tüm dosyaları (görsel, video, PDF, doküman vs.) merkezi olarak yönetmenizi sağlar. Üst menüden **CMS → Media Kütüphanesi** ile açılır.

## Özellikler

- **Yükleme** — tekli veya toplu dosya yükleme (sürükle-bırak)
- **Klasör Yapısı** — dosyaları klasörlere ayırma
- **Filtre** — dosya türü, tarih, boyut
- **Arama** — dosya adı ile
- **Önizleme** — görsel / video / PDF önizleme
- **Meta** — alt metin, başlık, açıklama
- **Kopyala** — URL veya kısa kod
- **Sil**

## Depolama

Dosyalar yerel diske veya CDN / R2 / S3 gibi harici depolara yüklenebilir. Depolama sağlayıcısı **Genel Ayarlar → Depolama** kısmından yapılandırılır.

Popup Yönetimi ekranı, sitede belirli koşullarda açılan modal / popup pencereleri yönetmenizi sağlar. Üst menüden **CMS → Duyurular & Popup** ile açılır.

## Popup Listesi

- **Başlık**
- **Tür** (Kampanya, Bülten, Duyuru, KVKK)
- **Gösterim** (Tüm ziyaretçiler / Sadece üyeler / İlk girişte)
- **Yayın Tarih Aralığı**
- **Durum**

## Yeni Popup

- **Başlık**
- **İçerik** (zengin metin / görsel)
- **Buton** (metin \+ link)
- **Gösterim Kuralı**:
  - Sayfa Yükleme Anında / X saniye sonra / Sayfayı terk ederken
  - Belirli sayfalar (URL kuralı)
  - Belirli rol (misafir / öğrenci)
- **Gösterim Sıklığı** (bir kez / her ziyarette)
- **Tasarım** (renk, boyut)
